# 3D-модель магазину ТОВ «Дитячий світ» (SketchUp)

Детальна модель торговельного залу за курсовою роботою (розділ 4): зал 25,0 × 16,0 м,
висота 3,3 м, 81 одиниця обладнання з таблиці 3.4, розміщення відділів — таблиця 3.3
і планограма (додаток Б).

| Файл | Що це |
|---|---|
| `dytiachyi_svit.rb` | **Основний варіант.** Скрипт будує модель прямо в SketchUp: 87 іменованих груп, матеріали, теги (Будівля / Обладнання / Навігація / Благоустрій), 3D-написи відділів і 6 сцен. |
| `dytiachyi_svit.dae` | Та сама модель у форматі COLLADA для «Файл → Імпорт» (без 3D-написів і сцен). |
| `build_model.py` | Генератор обох файлів (`python3 build_model.py`). |
| `preview/` | Рендери моделі. |

## Як відкрити в SketchUp

**Варіант 1 (рекомендовано):** новий файл з шаблоном «Метри» → *Вікно → Консоль Ruby* →
```
load 'C:/шлях/до/dytiachyi_svit.rb'
```
Побудова займає до хвилини. Після цього в меню *Вигляд → Анімація* є сцени:
«Загальний вигляд», «Вигляд від входу», «План зверху», «Відділ одягу та каси», «Дальня стіна», «Фасад».

**Варіант 2:** *Файл → Імпорт…* → тип файлу COLLADA (*.dae) → у «Параметрах» увімкнути
«Об'єднати компланарні грані».

## Що є в моделі

- стіни, фасад із вітринами, розсувні двері входу й виходу, килимки, вивіска, пандус, велопарковка;
- 29 стелажів-гірок із полицями й товарами відповідно до відділу (ляльки в коробках, будиночки для ляльок, м'ячі, машинки, техніка, книги тощо) та кольоровими фризами;
- 9 пристінних систем для одягу і 6 стійок-вішал з одягом на плечиках;
- 6 низьких стелажів із канцтоварами вздовж фасаду;
- 16 двосторонніх гондол (конструктори, розвиваючі ігри) з торцевими панелями;
- 4 подіуми: дитяча гірка з пісочницею, будиночок з гойдалкою, електромобілі та педальна машинка;
- 2 сітчасті кошики з м'ячами, 2 демонстраційні столи з табуретами;
- 2 касові бокси з моніторами й терміналами, 2 прикасові вітрини, 2 примірочні зі шторами й дзеркалами, шафа камери схову;
- підвісні навігаційні таблички над зонами.

Каси зсунуто праворуч від виходу (X = 5,0–6,8 та 7,8–9,6 м), щоб не перекривати прохід до виходу.
