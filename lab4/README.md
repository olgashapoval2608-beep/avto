# Лабораторна робота №4 — Організація набору даних у MySQL засобами MySQL Workbench (варіант 4)

- `Лабораторна_робота_4.docx` / `.pdf` — звіт.
- `library_lab4.sql` — створення схеми `library4`, таблиць `author`, `publisher`, `bookstore`, `book` та заповнення даними.
- `queries_lab4.sql` — запити (WHERE, реляційні/булеві оператори, IN, ORDER BY ASC/DESC, самостійні завдання).
- `img/` — скріншоти з MySQL Workbench 8.0.47 (сервер MySQL 8.0); `make_report.py` — збирає з них звіт.

Як відтворити в MySQL Workbench: File → Open SQL Script → `library_lab4.sql` → Execute (⚡),
потім так само `queries_lab4.sql`. Діаграма: Database → Reverse Engineer… → схема `library4`.
