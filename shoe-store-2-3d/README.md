# 3D-модель торговельної зали магазину взуття ТОВ «Взуття» (зала 20 × 14 м)

Модель для курсової роботи (п. 2.3): прямокутна зала 20,0 × 14,0 м (280 м²), висота 3,0 м, дверний проріз 2,0 м
посередині фасаду; зони з різним кольором підлоги — жіночий відділ 104 м², чоловічий 97 м², дитячий 55 м²,
вхідна і касова зона 24 м². Обладнання — табл. 2.2–2.3 (108 од.), розміщення — рис. 2.2.

| Файл | Що це |
|---|---|
| `vzuttia_zal.rb` | **Основний файл.** У SketchUp: *Вікно → Консоль Ruby* → `load 'шлях/до/vzuttia_zal.rb'`. Скрипт будує модель, зберігає поруч **`vzuttia_zal.skp`**, створює аркуш А1 у LayOut і експортує його в PDF. |
| `vzuttia_zal.dae` | Та сама модель у COLLADA для *Файл → Імпорт* (з кольорами, без компонентів і сцен). |
| `vzuttia_zal.stl` | Для безкоштовної онлайн-версії SketchUp (app.sketchup.com): *Імпорт* → одиниці «Міліметри» → *Зберегти як .skp* (без кольорів). |
| `build_model.py`, `export_stl.py` | Генератори. |
| `preview/` | Рисунки, вставлені в курсову (2.3, Б.1–Б.6). |

Обладнання — компоненти (10 визначень, 108 копій): пристінний стелаж 1000×400×1930 (47), острівний двосторонній
стелаж 1250×1000×1470 (39), банкетка 1000×350×450 (19), касовий прилавок 1000×600×900 (3). Одиниці моделі — міліметри.
