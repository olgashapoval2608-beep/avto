# 3D-модель торговельної зали продовольчого магазину ТОВ «Край» (SketchUp)

Модель для курсової роботи (п. 2.4): зала 28,0 × 20,0 м (560 м²), висота 3,2 м; вхід праворуч і вихід через
касовий вузол у фасадній стіні; 13 відділів і вхідна зона з різним кольором підлоги (табл. 2.1, рис. 2.2);
обладнання — табл. 2.2–2.3, 160 од. Координати обладнання розпізнано з рис. 2.2 курсової (`layout_fig2_2.json`).

| Файл | Що це |
|---|---|
| `kray.rb` | **Основний файл.** У SketchUp: *Вікно → Консоль Ruby* → `load 'шлях/до/kray.rb'`. Скрипт будує модель, зберігає поруч **`kray.skp`**, створює аркуш А1 у LayOut і експортує його в PDF. |
| `kray.dae` | Та сама модель у COLLADA для *Файл → Імпорт* (з кольорами, без компонентів і сцен). |
| `kray.stl` | Для безкоштовної онлайн-версії SketchUp: *Імпорт* → одиниці «Міліметри» → *Зберегти як .skp* (без кольорів). |
| `build_model.py`, `export_stl.py` | Генератори. |
| `preview/` | Рисунки, вставлені в курсову (2.3, Б.1–Б.6). |

Обладнання — компоненти (29 визначень = вид обладнання × відділ, 160 копій): пристінні стелажі 59, острівні 53,
стелажі для хліба 6, холодильні вітрини 14, холодильні гірки 11, морозильні лари 4, холодильні шафи 5, гірки для
овочів 2, касові бокси 6. Одиниці моделі — міліметри.
