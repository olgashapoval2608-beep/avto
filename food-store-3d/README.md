# 3D-модель продовольчого магазину ТОВ «Аеро-Експрес» (SketchUp)

Модель для курсової роботи (розділ 4): одноповерхова будівля 25,0 × 25,0 м — торговельна зала
25,0 × 16,0 м заввишки 3,6 м і тильний блок підсобних приміщень глибиною 9,0 м (рис. 3.1, табл. 3.1).
Обладнання — 49 одиниць за табл. 3.4, розміщення — за планограмою (рис. 3.2).

| Файл | Що це |
|---|---|
| `aero_express.rb` | **Основний варіант.** Скрипт будує модель у SketchUp: іменовані групи, матеріали, теги (Будівля / Обладнання / Підсобні приміщення / Навігація / Благоустрій), 3D-написи відділів і приміщень, 7 сцен. |
| `aero_express.dae` | Та сама модель у COLLADA для «Файл → Імпорт» (без написів і сцен). |
| `build_model.py` | Генератор (`python3 build_model.py`), використовує примітиви з `../toy-store-3d/build_model.py`. |
| `preview/` | Рисунки, вставлені в курсову. |

## Як відкрити

**Скрипт (рекомендовано):** новий файл із шаблоном «Метри» → *Вікно → Консоль Ruby* →
`load 'C:/шлях/до/aero_express.rb'`. Побудова займає 1–2 хвилини. Сцени: «Загальний вигляд»,
«Вигляд від входу», «План зверху», «Каси», «Острівні стелажі», «Гастрономія та молочний відділ»,
«Підсобні приміщення».

**Імпорт:** *Файл → Імпорт…* → COLLADA (*.dae) → у параметрах увімкнути «Об'єднати компланарні грані».

## Склад моделі

- **Торговельна зала:** 5 острівних стелажів «Колумб» (5 секцій, 1625 мм) з товарами за відділами;
  8 пристінних секцій (хліб, алкоголь); 8 холодильних гірок (риба, ковбаси, гастрономія, молочні);
  3 вітрини-прилавки гастрономії з вагами; стелаж за прилавком; 6 холодильних шаф зі скляними дверима;
  3 морозильні бонети; 3 гірки для фруктів та овочів з ящиками; 4 касові бокси Magellan з транспортером,
  сканером, монітором і кріслом касира; 4 прикасові стелажі; 2 столи для пакування; 2 камери схову;
  підвісні покажчики відділів.
- **Будівля:** фасад, вхід через тамбур, окремий вихід, стіни із сендвіч-панелей. Як у п. 4.1 курсової, передні та бокові стіни занижено до 1,0 м, покрівлю не показано.
- **Маршрут покупців** (рис. 3.2) — червоні пунктирні стрілки на підлозі.
- **Підсобний блок:** 18 приміщень за рис. 3.1 з дверними прорізами та обладнанням (піддони, стелажі
  комори й холодильних камер, фасувальні столи, меблі кабінетів і кімнати персоналу, щити, агрегати).
- **Ділянка:** автостоянка з розміткою, рампа і ворота приймальної, тротуар, велопарковка.
